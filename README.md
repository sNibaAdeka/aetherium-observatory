# Aetherium Observatory

An interactive WebGL observatory concept for exploring scientific data as a calm, spatial experience. This prototype focuses on cinematic motion, layered information, and a responsive single-page presentation.

## Highlights

- interactive 3D-inspired visual scene;
- responsive layout for desktop and mobile;
- lightweight static build with no private credentials;
- visual language for future science and climate-data products.

## Run locally

Open `index.html` in a browser or serve the folder with any static web server.
